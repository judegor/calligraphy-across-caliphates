# Calligraphy Across Caliphates

**Calligraphy Across Caliphates** is a digital humanities project that traces the historical development of Islamic calligraphy styles across different caliphates and regions. The project combines scholarly research with interactive visualizations to make the art and history of Arabic, Persian, and Ottoman calligraphy accessible to a wide audience.

## Overview

This repository contains the source code and content for the website **Calligraphy Across Caliphates**, which features:
- A visual timeline of major calligraphy styles.
- High-resolution images of calligraphic works.
- Historical context for each script style.
- Annotations and references to academic sources.

The project is built with:
- **Hugo** (static site generator)
- **TimelineJS** (interactive timeline)
- **Leaflet.js** (interactive maps)
- Custom HTML, CSS, and JavaScript

## Features

- **Interactive Timeline:** Explore when each calligraphy style emerged and evolved.
- **Style Galleries:** Browse curated examples of Kufic, Naskh, Thuluth, and more.
- **Contextual Essays:** Learn about the cultural and historical significance of each script.
- **Open Access References:** Links to digitized collections (e.g., The Met, Library of Congress).
